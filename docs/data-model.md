# VYBE MVP - Data Model

## Overview

All entities follow these conventions per spec:
- **ID**: UUID v4 (generated by Prisma)
- **Timestamps**: `createdAt`, `updatedAt` (auto-managed), `deletedAt` (nullable for soft delete)
- **Soft delete**: Most entities use soft delete (`deletedAt IS NOT NULL`)

## Entity Relationship Diagram (Conceptual)

```
User ──┬── AuthIdentity (1:N)
       ├── PasswordCredential (1:0..1)
       ├── Device (1:N)

       ├── FriendEdge (userA/userB)

       ├── MuteEdge (owner/target)
       ├── Circle (owner) ── CircleMember (N:N)
       │
       ├── ContentItem (author) ── ContentMedia ── MediaAsset
```

## Indexes Strategy

### Performance-Critical Indexes
- `user.username` - UNIQUE, used in login and search
- `user.email` - UNIQUE, used in login
- `user.phone` - UNIQUE, used in login
- `follow_edge(followerId, followeeId)` - UNIQUE composite
- `follow_edge(followeeId)` - For followers list
- `content_item(authorId, status, publishedAt)` - Profile feed
- `content_item(status, audience, publishedAt)` - Discovery feed
- `comment(contentId, status)` - Comment threads
- `reaction(targetType, targetId)` - Reaction counts
- `message(conversationId, createdAt)` - Chat history
- `notification(recipientId, isRead, createdAt)` - Notification list
- `analytics_event(eventType, createdAt)` - Analytics queries
